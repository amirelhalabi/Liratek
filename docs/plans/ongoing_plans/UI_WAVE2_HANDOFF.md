## Order of work

1. **A. Money bugs first.** They can book money twice or book the wrong amount:
   - Katsh failed bill leaves sold items in the cart.
   - MTC/Alfa totals at cost but books at sell when the price is empty.
   - Recharge payment window closes before the save ends.
   - Debts Settle and Add Credit/Debt book twice on a double click.
   - OMT/Whish tab switch turns LBP into USD.
   - OMT/Whish typed fee of 0 is ignored.

   These are money changes: read `docs/FEATURE_GUIDE.md` §13, write the guard test first and see it fail (CLAUDE.md rule 17), and prove desktop and web (rule 19).

2. **B. Cashier safety.** Cancel order with a confirm step, cart remove button visible on touch, Owes/Credit words on Accounts, client name in the Settle window, Send/Receive on OMT tabs.
3. **C. Motion.** Run the 4 plans in `ui-wave2/motion-plans/` in order. Do not install `tw-animate-css` (it would switch on a 500ms page fade on 20 pages).
4. **D. Landing.** One primary button, remove the leftover hero padding and dead CSS, tighter screenshot crops, sign-in strip below the closing section, Arabic Sign in link (`?lang=ar`), placeholder contrast.
5. **E. App-wide polish.** One money formatter (tabular digits, thousands separators), label grey from #77746b to #59574f.

Each group can run as parallel agents if each owns separate files. Every visible change needs its release note and What's new card (CLAUDE.md rule 30).

## Quick notes

- **Bugs found while capturing, not in the reports**:
  - A fresh admin sign-in crashes the app in `frontend/src/features/closing/components/DrawerCard.tsx:54` (reads `.color` of undefined). Reload gets past it. Seen twice on the local sample shop.
  - Red buttons styled `bg-red-600/80 text-white` show dark text in light mode (`index.css` only exempts the solid `.bg-red-600.text-white`).
  - The Profits error box title (`text-red-200`) is nearly invisible in light mode.
- **Already confirmed by running**:
  - OMT 900,000 LBP becomes a $900,000.00 total after a tab switch.
  - Add Credit/Debt is clickable with both amounts empty (`parseFloat("")` is NaN, and `NaN <= 0` is false).
  - MTC Credit Proceed is enabled with no price.
